# BoolenLoops

BoolenLoops is a beginner-level C# console application created during The Tech Academy’s Basic C-Sharp course. The project focuses on boolean expressions and loop control flow, showing how conditions and repetition work together in a program.

## What This Project Covers
- Boolean variables and logical operators  
- Looping structures (while, do-while)  
- Conditional statements  
- Basic user interaction through the console  

## Purpose
This assignment builds foundational understanding of how programs make decisions and repeat tasks, preparing for more advanced C# concepts later in the curriculum.

## Running the Project
Open the solution in Visual Studio and press **Start** to execute the program.
