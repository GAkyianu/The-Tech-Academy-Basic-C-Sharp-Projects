Six-Part C# Console App Assignment

Project Overview

This project contains a six-part C# Console Application assignment completed as part of The Tech Academy's C# training programme.

The assignment focuses on developing fundamental programming skills through practical exercises involving arrays, lists, loops, conditional statements, user input and duplicate detection.

Assignment Breakdown

Part 1: String Array and User Input

Created a one-dimensional array of strings.

Asked the user to enter text.

Used a for loop to append the user's input to each string.

Used a second loop to display the updated strings.

Part 2: Infinite Loop

Demonstrated an example of an infinite loop.

Corrected the loop by introducing a counter.

Used a condition to ensure the loop eventually terminates.

Part 3: Comparison Operators

Created a loop using the less-than (<) operator.

Created another loop using the less-than-or-equal-to (<=) operator.

Demonstrated the difference between the two comparison operators.

Part 4: Searching a List

Created a list containing unique strings.

Asked the user to enter text to search for.

Used a loop and the Contains() method to find a matching item.

Displayed the index of the matching item.

Used a break statement to stop the loop after finding the first match.

Displayed a message if the search text was not found.

Part 5: Finding Multiple Matches

Created a list containing repeated strings.

Asked the user to enter text to search for.

Used a loop to identify and display all matching indices.

Removed the break statement to allow the loop to find multiple matches.

Displayed a message if no matching item was found.

Part 6: Identifying Unique Items and Duplicates

Created a list containing duplicate strings.

Used a foreach loop to examine each item.

Created a second list to track previously encountered items.

Used the Contains() method to identify duplicates.

Displayed whether each item was unique or a duplicate.
