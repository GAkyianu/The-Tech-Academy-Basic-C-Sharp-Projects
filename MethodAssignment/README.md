# Method Assignment

## Description

This console application demonstrates the use of methods with optional parameters in C#.

The program:

- Creates a class containing a method with two integer parameters
- Uses an optional parameter with a default value
- Accepts user input from the console
- Performs a multiplication operation
- Returns and displays the result

## Technologies Used

- C#
- .NET
- Visual Studio 2022

## Example Output

```text
Enter an integer:
5
Enter a second integer, or just press Enter:
3

5 x 3 = 15
```

```text
Enter an integer:
5
Enter a second integer, or just press Enter:

5 x Default 1 = 5
```
