# ArrayAssignment — C# Console Application

This project is part of *The Tech Academy Basic C# Projects*.  
It demonstrates how to work with one-dimensional arrays and lists in a C# console application.

---

## 📌 Features

- Creates a **string array** and allows the user to select an index  
- Creates an **integer array** and allows the user to select an index  
- Creates a **list of strings** and allows the user to select an index  
- Includes **index validation** to prevent crashes  
- Uses `int.TryParse()` for safe input handling  
- Displays helpful error messages when the user selects an invalid index

---

## 🧪 Sample Output

Select an index from the string array (0 to 4):

Select an index from the integer array (0 to 4):

Select an index from the string list (0 to 3):
