# Class Method Assignment

## Description

This console application demonstrates the use of a void method and named parameters in C#.

The application:

- Creates a class containing a void method
- Accepts two integer parameters
- Performs a mathematical operation on the first integer
- Displays the second integer to the screen
- Demonstrates calling a method normally
- Demonstrates calling a method using named parameters

## Technologies Used

- C#
- .NET
- Visual Studio 2022

## Example Output

First number multiplied by 2: 20
Second number: 20

First number multiplied by 2: 60
Second number: 40
