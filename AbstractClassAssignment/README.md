Abstract Class Assignment

Description

This console application demonstrates the use of abstract classes and inheritance in C#.



The application contains:



An abstract Person class

Properties for firstName and lastName

An abstract method called SayName()

An Employee class that inherits from Person

An implementation of the SayName() method in the Employee class
