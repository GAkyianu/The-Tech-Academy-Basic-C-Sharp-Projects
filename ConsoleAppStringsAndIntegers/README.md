Console App Strings and Integers Assignment

Project Overview

This project is a C# Console Application created as part of The Tech Academy C# training programme.

The assignment demonstrates how to work with lists of integers, user input, loops, division and exception handling using try/catch blocks.

Assignment Requirements

List of Integers: Created a list containing integer values.

User Input: Asked the user to enter a number to divide each item in the list by.

Division: Used a loop to divide each integer by the user's input and display the results.

Exception Handling: Used a try/catch block to handle errors.

Error Testing: Tested the application using valid numbers, zero and text input.

Code Comments: Added comments explaining the purpose of the code.

Testing

The application was tested using three different inputs:

2 – Successfully divided each number in the list.

0 – Successfully caught the division-by-zero exception.

Rose – Successfully caught the invalid input format exception.

The application also displays a continuation message after the try/catch block.
