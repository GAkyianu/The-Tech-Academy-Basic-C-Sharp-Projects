Calling Methods Assignment
Project Overview
This project is a C# Console Application developed as part of The Tech Academy C# and .NET Developer Boot Camp.

The purpose of this assignment is to demonstrate the creation and use of methods, including passing parameters, returning values, and organising code into reusable and maintainable components.

Features
Created custom methods to perform mathematical operations.
Passed user input as parameters to methods.
Returned values from methods and displayed the results.
Separated functionality into multiple methods for better code organisation.
Included comments to improve code readability and understanding.

How It Works
The application:

Prompts the user for a number.
Passes the number to several methods.
Performs different mathematical operations.
Returns the calculated values.
Displays the results in the console.
